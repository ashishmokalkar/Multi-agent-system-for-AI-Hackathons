# Control-room recording storyboard

> This is the legacy 60–90-second storyboard. The active 14-second social demo is documented in [HIGHLIGHT_REEL.md](HIGHLIGHT_REEL.md).

Target: a 60–90-second edited capture at 1920×1080. Use Presentation mode and
keep the mode-provenance badge visible throughout.

| Time | Picture | Narration / caption |
|---:|---|---|
| 0–10 s | Objective banner and seven-agent workflow | “A bounded audio experiment enters a guarded team; unused specialists stay idle.” |
| 10–22 s | Coordinator, data investigator, and research cards change from queued to active | “Delegation and split checks are driven by persisted agent events.” |
| 22–38 s | Waveform/spectrogram and three annotation lanes | “The generated chirp has an explicit 0.750–1.250 second reference. No semantic claim comes from energy alone.” |
| 38–52 s | Evaluator rejection and highlighted initial boundary | “A deterministic tool measures both boundary errors and requests one bounded revision.” |
| 52–66 s | After-revision toggle, corrected interval, evaluator acceptance | “The synthetic engineer changes only the rejected fields; the evaluator reruns the same check.” |
| 66–78 s | Baseline-versus-candidate fixture metrics and coordinator completion | “Actual CPU scoring is labeled as toy fixture evidence—not leaderboard performance.” |
| 78–90 s | Completed team and repository footer | “The repository includes live, replay, and offline mock modes with inspectable artifacts.” |

Pause replay briefly on the rejected and corrected boundary views if the edit
needs more reading time. Do not add fake progress bars, metrics, agent messages,
or delays to the live workflow.
